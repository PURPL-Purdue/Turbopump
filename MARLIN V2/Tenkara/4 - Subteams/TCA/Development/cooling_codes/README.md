# Standards
### Naming Conventions
 - Variables are camelCase
 - Functions are lowercase_underscore_spaced

## Files
### Header (Template found at headers.txt)
 - Author
 - Created Date
 - Last Modified Date
 - Function Index

## Functions
### Header (Template found at headers.txt)
 - Description
 - Methods
 - Arguments
 - Returns
   - ex. varName (type) Description
